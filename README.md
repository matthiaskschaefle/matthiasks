# Matthias Schaefle Portfolio

UX/UI portfolio website for Matthias Schaefle, built with React, Vite, Tailwind CSS, and Framer Motion.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Routes

- `/` - selected work
- `/about` - profile
- `/delivery` - delivery app case study
- `/duopet` - DuoPet case study
- `/doctor` - healthcare website redesign case study

## Notes

Generated files such as `dist`, `dist_extracted`, ZIP archives, dependencies, logs, and local environment files are intentionally ignored by Git.
